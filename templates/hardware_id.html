💻 Wie finde ich meine SkyTycoon Hardware-ID?

Um Ihre Lifetime-Lizenz sicher an Ihren Simulator-PC zu koppeln, benötigt unser System Ihre eindeutige Windows-Hardware-UUID. Diese Anleitung funktioniert fehlerfrei unter Windows 10 und Windows 11.

Hinweis: Der alte Befehl wmic ist unter Windows 11 entfernt und erzeugt eine Fehlermeldung. Verwenden Sie ausschließlich den modernen PowerShell-Befehl unten.

Schritt 1: Windows PowerShell öffnen

Drücken Sie die Windows-Taste, tippen Sie powershell ein und drücken Sie Enter.

Schritt 2: Befehl kopieren und ausführen

Kopieren Sie den folgenden Befehl, fügen Sie ihn mit einem Rechtsklick in die PowerShell ein und drücken Sie Enter:

(Get-CimInstance Win32_ComputerSystemProduct).UUID

Schritt 3: ID kopieren und eintragen

PowerShell gibt Ihre 36-stellige UUID aus (z. B. A1B2C3D4-E5F6-7890-ABCD-EF1234567890). Kopieren Sie diese Zeile und tragen Sie sie bei der Produkt-Aktivierung oder im Kundenportal ein.

💡 Tipp: Beim ersten Start von main.py liest SkyTycoon Pro diese ID automatisch aus. Sie können sie auch über [📋 Aus Zwischenablage] einfügen.

English

💻 How do I find my SkyTycoon hardware ID?

Works on Windows 10 and Windows 11. Do not use wmic on Windows 11 — it was removed by Microsoft.

Step 1: Open Windows PowerShell

Press the Windows key, type powershell, press Enter.

Step 2: Run this command

(Get-CimInstance Win32_ComputerSystemProduct).UUID

Step 3: Copy your ID

Copy the UUID into product activation or your customer portal.
